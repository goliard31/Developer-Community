# 使用指南（测试数据）

> 本文件为端到端测试素材，用于验证二级目录中的 Markdown 与相对路径图片引用。

## 概述

本指南介绍示例项目的基本用法。所有内容均为**测试数据**，仅用于上传功能验证。

项目的整体结构可以用下面的示意图概括：

![示意图](../images/diagram.png)

## 使用步骤

1. 准备好待上传的项目目录；
2. 在页面上选择"上传项目"入口；
3. 勾选需要包含的文件类型：
   1. Markdown 文档；
   2. 源代码文件；
   3. 图片资源；
   4. 媒体资源；
4. 点击"开始上传"，等待进度条完成；
5. 上传完成后，在预览页核对文件清单。

## 常见问题

- **上传失败怎么办？** 测试环境下可忽略，重新上传即可。
- **图片不显示？** 请检查相对路径 `../images/diagram.png` 是否正确解析。
- **视频无法播放？** 请确认浏览器支持 MP4（H.264）格式。

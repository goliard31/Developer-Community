# 示例项目（测试数据）

> **本文件为端到端测试素材，内容纯属虚构，仅用于验证上传功能与 Markdown 渲染，请勿在实际项目中使用。**

## 项目简介

**示例项目** 是一个用于测试的演示工程，模拟用户上传的一个典型前端项目结构。它包含源代码、文档、图片、媒体与数据文件，覆盖上传功能需要处理的各类文件类型。

本项目声明如下：

- 所有代码与文本均为**测试数据**；
- 不代表任何真实业务逻辑；
- 可随时删除，不影响主工程。

## 功能特性

- 支持多级目录结构展示
- 支持常见文件类型上传（Markdown / TypeScript / PNG / MP4 / JSON）
- 渲染效果覆盖：标题、列表、表格、引用、代码块

## 快速开始

安装依赖并启动开发服务器：

```bash
pnpm install
pnpm dev
```

在代码中引用示例模块：

```ts
import { createStore } from "./src/index";

const store = createStore("demo");
store.set("answer", 42);
console.log(store.get("answer"));
```

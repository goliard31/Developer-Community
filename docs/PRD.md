# 04｜信息架构与页面设计

## 网站地图与页面清单

本地完整应用（Next.js App Router，2026.11.23 起）实际路由如下：

| 路由 | 页面 | 权限 | 说明 |
|---|---|---|---|
| / | 首页 | 公开 | 社区介绍、CTA、三个开发组入口、最新上传项目、深色 CTA |
| /groups/project、/groups/rd、/groups/design | 组项目主页 | 公开 | 置顶项目区 + 项目卡片列表 + 空状态 |
| /projects/[id] | 项目仓库页（原"项目展示页 + 项目详情页"合并） | 公开 | GitHub 风格：左侧目录树 + 右侧文件表（名称 / 类型 / 大小 / 查看 / 下载）；所有者与管理员可置顶、追加文件、删除 |
| /projects/[id]/blob/[...path] | 文件浏览页 | 公开 | 按类型分流：代码 / 文本高亮、Markdown 渲染、图片、视频播放、其他类型给下载 |
| /login、/register | 登录 / 注册 | 公开（已登录跳转 /dashboard） | 注册即普通用户，首个注册用户为管理员 |
| /upload | 上传项目 | 需登录 | 新建项目或向已有项目追加文件；支持选择文件与选择文件夹 |
| /dashboard | 我的项目 | 需登录 | 本人项目列表、上传入口、退出登录、管理员入口 |
| /admin | 管理后台 | 仅管理员 | 用户与项目统计、用户角色管理、项目置顶与删除 |
| /api/auth/register、/api/auth/login、/api/auth/logout | 认证接口 | — | 登录态写入 httpOnly cookie（cp_session，7 天） |
| /api/projects、/api/projects/[id] | 项目接口 | — | 列表 / 新建（multipart）/ 追加文件 / 更新 / 删除 |
| /api/files/[...path] | 文件接口 | — | 按相对路径取文件，支持 HTTP Range（视频边下边播） |
| /api/admin/users/[id] | 用户管理接口 | 仅管理员 | 修改角色、删除用户（连带删除其项目与会话） |

项目展示页与项目详情页在本地版中合并为"项目仓库页 + 文件浏览页"：原两页 Demo 中的封面 / 简介 / 成果卡片由项目标题与简介取代，项目文件 / 图文教程 / 视频教程三类内容直接以真实上传文件呈现。

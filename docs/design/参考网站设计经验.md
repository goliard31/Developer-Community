# 参考网站设计经验（wokine.com · danielspatzek.com）

> 整理时间：2026.11.21 · 整理人：Agent
> 用途：为「社区项目站」首页 / 三个组项目主页 / 项目展示页 / 项目详情页的页面布局提供设计经验依据。
> 说明：两个站点均为外部公开网站，本文只提炼**布局与组件模式**，不代表本项目视觉规范（色值 / 字体 / Logo 仍待确认，见 PRD 第 07 章）。

## 二、设计原则（来自 danielspatzek.com 的设计准则，直接引用并落地）

原站以 "Thou shalt …" 形式列出一系列设计戒律，其中可迁移到本项目的：

1. **Thou shalt not overload your Landing Page** —— 首页不堆砌：首页只放社区介绍、三组入口、页脚。
2. **Thou shalt keep it clean and simple** —— 干净简单：一屏一个主题，区块之间用留白与分隔带区分。
3. **Thou shalt not use effects for no reason** —— 动效必须有理由：本站唯一功能动效是 CTA 平滑滚动；marquee 仅为分隔装饰，且可用系统偏好降级。
4. **Thou shalt not create a hidden section nobody can find** —— 不设隐藏区块：所有入口都在导航或正文可见。
5. **Thou shalt not change your design style within a project** —— 项目内不换风格：全站统一黑白线框、统一导航栏与页脚。
6. **Thou shalt not write vertical** —— 不竖排文字。
7. **Thou shalt not confuse people** —— 不让人困惑：占位内容明确标注"占位 / 待提供"。
8. **Thou shalt not choose UI over UX** —— UX 优先于 UI：先保证"能找到组 → 能看到项目 → 能进展示页 → 能进详情页"的链路，再谈样式。

## 三、布局与组件模式（来源表现 → 本站应用）

### P1 公告条（来源：wokine.com）
- **来源表现**：导航栏上方一条窄公告（"Nouveau — Wokine s'installe à Annecy"），承载最新动态。
- **本站应用**：所有页面在导航栏上方加 `.announce` 公告条，内容为社区动态占位（待提供）。

### P2 锚点导航（来源：danielspatzek.com 单页锚点 + wokine.com 极简导航）
- **来源表现**：Spatzek 首页导航即锚点（Intro / Work / About / Process / Faq / Contact）；Wokine 导航只有 logo + 电话 + 语言切换。
- **本站应用**：导航 = logo + 锚点（认识社区 `#about` / 开发组 `#groups`）+ 右侧按钮（行为待确认）；子页面锚点指向首页对应区块。

### P3 Hero 大字号主张（来源：danielspatzek.com）
- **来源表现**：超大字号标题（"Portfolio IV"）+ 一句直白介绍，不堆图片。
- **本站应用**：首页社区介绍区改为 eyebrow 小标签 + 大字号主标题 + 直白介绍文案 + CTA。

### P4 直白介绍文案（来源：danielspatzek.com）
- **来源表现**：开场白直接用口语说明"你是谁、你能得到什么"（"Since you landed here you are probably looking for someone who can build your new website…"）。
- **本站应用**：社区介绍文案占位按此风格撰写：这个网站是做什么的、访客能做什么（内容待机构提供）。

### P5 区块解剖学：eyebrow + 标题 + 副标题 + 次级链接（来源：wokine.com）
- **来源表现**：每个区块都是「小标签（## Nos expertises）+ 标题 + 一句副标题 + "Toutes nos expertises" 次级链接 + 卡片网格」。
- **本站应用**：`.section-head` 组件替换原盒状 `.section-label`：eyebrow（分类小字）+ 标题 + 副标题；组项目主页右侧加"返回首页"次级链接。

### P6 卡片解剖学：标题 + 标签 + ✦ 分隔（来源：wokine.com）
- **来源表现**：portfolio 卡片 = 项目名 + 行业标签 + 类型标签，中间用 ✦ 分隔（"Chicorée Leroux · Agroalimentaire ✦ E-commerce"）。
- **本站应用**：三组入口卡片与项目卡片统一加 `.tags` 标签行（方向 / 项目数 / 年份 / 类型，均为占位），标签间用 ✦ 圆点区分。

### P7 Marquee 文字分隔带（来源：wokine.com + danielspatzek.com）
- **来源表现**：Wokine 用重复大标题（"Nos réalisations ×9"、"Inside Wokine ×10"）做滚动分隔带；Spatzek 用重复戒律文字做跑马灯。
- **本站应用**：首页与组项目主页加 `.marquee` 装饰带（社区口号 / 组名重复），纯 CSS 动画，`prefers-reduced-motion` 时静止，`aria-hidden` 对读屏隐藏。

### P8 项目列表模式：标题 + 年份 + 领域标签 + 外链（来源：danielspatzek.com）
- **来源表现**：作品列表每项 = 大标题 + 年份 + 领域标签（Webdesign / Development / Branding）+ "LAUNCH WEBSITE"。
- **本站应用**：组项目主页卡片 = 项目名 + 标签（年份 / 类型占位）+ 进入箭头；项目展示页成果卡片加类型标签。

### P9 多列页脚 + 法律行 + 返回顶部（来源：wokine.com + danielspatzek.com）
- **来源表现**：Wokine 页脚为多列（品牌简介 / 两组链接 / 新闻通讯 / 地址）+ 法律与 Cookie 行；Spatzek 页脚有 "BACK TO TOP"。
- **本站应用**：全站统一多列页脚（品牌+简介 / 站点导航 / 联系与社交）+ 底部行（版权占位 + 返回顶部）。

### P10 社会证明（来源：wokine.com；后续版本再议）
- **来源表现**：奖项行（Awwwards / CSSDA / FWA 徽标）、客户 logo 墙、按合作年限叙述的客户卡片。
- **本站应用**：本期不实现（无真实数据，不编造）；后续版本可在首页加"社区数据 / 项目数量"一类模块，数据待确认。

## 五、明确不采纳的部分（避免过度设计）

| 不采纳 | 原因 |
| --- | --- |
| 入场 Loading 动画、欢迎 marquee（danielspatzek.com） | 静态 Demo 收益低，违反"动效必须有理由" |
| 3D 香蕉、彩蛋隐藏区块 | 违反"不设隐藏区块" |
| 竖排文字、非常规排版 | 违反"不竖排、不困惑"；且中文竖排可读性差 |
| 花哨 hover 特效 | 保持黑白线框的反色悬停即可，符合"干净简单" |

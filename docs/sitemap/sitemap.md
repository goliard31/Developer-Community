## 结构树

```
首页 (/)
├── 项目组项目主页 (/groups/project)
│   └── 项目n（登录用户可上传多个）
│       └── 项目仓库页 (/projects/[id]) → 文件浏览页 (/projects/[id]/blob/[...path])
├── 研发组项目主页 (/groups/rd)
│   └── 项目n（同上）
└── 设计组项目主页 (/groups/design)
    └── 项目n（同上）

账号与功能
├── /login、/register        登录 / 注册
├── /upload                  上传项目（?group= 预选组，?project=[id] 追加文件）
├── /dashboard               我的项目
└── /admin                   管理后台（仅管理员）

接口
└── /api/auth/*、/api/projects*、/api/files/*、/api/admin/users/*
```

原"项目展示页 + 项目详情页"两个二级页面已合并为**项目仓库页**与**文件浏览页**（2026.11.23 用户确认）。

> 2026.11.23 起视觉全面采用 discourse.org 设计语言（用户确认），全面舍弃线框式设计；此前依据的线框参考图仅作历史记录。设计令牌见 `docs/TECH_STACK.md` 第 6 节，采集数据在 `D:\Blog\copycat\www.discourse.org`。

- 导航栏：Logo + 锚点导航（首页 / 关于▾ / 开发组 / 项目）+ 右侧"上传项目"与登录态入口（我的项目 / 管理后台）+ 移动端汉堡；固定定位，初始透明（深色 hero 上用白色文字），滚动后变白底 + 阴影。
- 页脚：全站统一，浅紫渐变 5 列结构（品牌 + 社区 / 开发组 / 使用 / 说明 + 社交圆图标 + 版权行）。
- 设备约束：电脑优先；本地应用首页已做响应式（390px 单列），完整手机端适配时间待确认。
- 已废止（2026.11.23）：导航上方公告条、marquee 分隔带、深色描边圆角线框卡片。
